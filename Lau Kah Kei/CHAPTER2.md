## 四、三段玩法规格

### 阶段一：环境探索

- 走近物件 → 屏幕下方提示「按 E 调查」
- 按 E → 弹出文字框，显示这个物件的描述
- 物件清单：床 ×3（A-03 那张上面有合照）、书桌、抽屉、衣柜、旧乐器堆、电脑、笔记
- 拿到东西要进背包，按 I 可以打开看已收集的证据

**拿东西的统一流程（所有物品都一样，不准跳过）**：

```
走近      → 提示「Press E to pick up」
按 E      → 东西放大到屏幕中间（ItemView），玩家先看清楚是什么
按 E      → 背面有字的才翻面（例如合照），没有就跳过这步
按 E      → 才真的进背包，物件消失，Kunkun 讲一句
```

- 地上／床上捡的东西：Area2D 挂 `scripts/pickup.gd`，Inspector 填 `item_id`（ItemDB 的 id）就好，
  放大图默认用 ItemDB 里那个 icon。背面写字的填 `back_texture`。
- 抽屉、电脑这种「调查后才给东西」的：还是用 `scripts/interactable.gd`，
  填了 `item_id` 就会自动接上同一套放大 → 按 E 收进背包的流程。
- 放大画面是 autoload `ItemView`（`scenes/item_view.tscn`），排版在编辑器里改，
  每个房间不用再自己摆一个 Closeup 节点。
- 捡过的东西 GameState 记得住，再进房间不会又躺在地上。

**摆物件的两条硬规矩**（踩过坑了）：

1. **两个可互动的东西，触发区中心至少隔 150px。** 玩家的碰撞圈半径是 70px
   （直径 140），两个 Area2D 靠太近的话，玩家站在中间会同时压到两个，
   底下那个共用的提示 Label 就会乱跳、按 E 谁响应看运气。
2. **靠太近就别分成两个** —— 让家具直接把东西给玩家：`interactable.gd` 填
   `item_id` + `item_node`（指向那个物件的 Sprite，收进背包后自动藏起来）。
   A-03 的床给照片、A-05 的乐器堆给钥匙，都是这样做的。

**引导信息放进房间台词，不要放在物件上**：`scripts/room_intro.gd` 挂在房间根节点，
第一次进这个房间自动播（flag 记住，之后不再播）。因为玩家可能任何顺序调查，
物件台词不能假设「你已经看过 XX 了」，但进门那句一定最早触发。

**证据 1 —【舍友的信物】**：A-03 摆在 Ricardo 叠好的床铺上，不是丢在地上。
一张合照，背面写着「别忘了我」—— 像是他特意留给 Kunkun 的。

### 阶段二：潜行（在监控室 A-02 内部）

> 注意：策划书英文版写巡逻在走廊，**以中文剧情稿为准 —— 潜行发生在监控室里面**。

- 傀儡老师在监控室内沿固定路线巡逻
- **背对玩家 = 安全**，转身面向玩家 = 会被发现
- 桌子、柜子是**遮蔽物**，躲在后面不会被看到
- 被发现 → 送回走廊入口，要重新开门进 A-02

### 阶段三：碎片重组（核心谜题）

电脑屏幕显示 3 段监控录像缩略图，顺序打乱，玩家拖到时间轴上：

| 碎片 | 时段 | 画面 |
|---|---|---|
| A | 上午 | Ricardo 正常在走廊走路 |
| B | 下午 | Ricardo 被一个黑影拉住手臂 |
| C | 夜晚 | Ricardo 被拖进走廊尽头的门，门牌 **B-13** |

排对 → 播放完整录像，最后定格在 Ricardo 被拖入 B-13 的瞬间，
嘴型放大，字幕：「别……」

**证据 2 —【异常日志U盘】**：主机侧面一个不起眼的 USB 接口，点了弹出隐藏文件：
> 「循环记录：第 114 次。警告：核心能量不足。」

**关卡结尾**：监控室抽屉里拿到 **B-13 钥匙** → 渐黑 → 「我必须去 B-13 看看。」

**共用代码接口**（已经写好，在 `scripts/game_state.gd` + `scripts/item_db.gd`）：

```gdscript
GameState.add_item("torn_diary_page")   # 第 1 关拿到日记页时呼叫
GameState.evidence_count()              # 第 3 关判结局时读，回传 0~3
GameState.has_item("anomaly_usb")       # 结局 3 想确认玩家拿过 U盘
```

物品的名字和描述统一写在 `ItemDB.ITEMS` 里，加新物品只改那一个档案。
**游戏内文字一律用英文**，这份文件的中文只是组内沟通用。

判定规则（第 3 关用）：

- 证据 < 2 + 开保险柜 → 结局 1：循环
- 证据 ≥ 2 + 开保险柜 → 第 4 关 → 结局 2：进轮回
- 证据 ≥ 2 + 剪电线 → 结局 3：生还者

> 结局 3 的剧情设定是「U盘里其实有求救代码，不知不觉触发了警笛」，
> 所以走结局 3 **必须拿到 U盘**。要跟 Lew Jia Jia 讲一声。
